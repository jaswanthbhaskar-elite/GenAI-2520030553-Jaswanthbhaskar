# Week 6 – Generative AI Programming Practical

## Objective

Create a golden question set containing questions, expected answers, keywords, and reference sources. Evaluate the responses generated by a locally running Llama 3.2 model and establish the first evaluation baseline.

**Release:** v0.1  
**Model:** Llama 3.2  
**Framework:** Ollama  
**Language:** Python

## Technologies Used

- **Python** – Implementation of the evaluation program.
- **Ollama** – Runs the Llama 3.2 model locally.

- **JSON** – Stores questions, expected answers, keywords, and sources.

## Implementation

### 1. Ollama Setup

Installed and configured Ollama to run language models locally.

Checked the installed version and verified the availability of the Llama 3.2 model.

```powershell
ollama --version
ollama list
```

### 2. Golden Question Set

Created `golden_set.json` containing 30 questions (Q001–Q030).

The questions cover topics including:

- Tokenization and tokenizers
- BPE, WordPiece, and SentencePiece
- Token ratios and token economics
- Input and output tokens
- API costs and context windows
- Rate limits and monitoring
- Autoregressive generation
- Next-token prediction
- Probability distributions
- Greedy decoding and sampling
- Temperature, Top-K, and Top-P
- Embeddings and token IDs
- Positional encoding and RoPE
- Transformer architecture

Each question contains:
- Question ID
- Question
- Expected answer
- Keywords
- Reference source

### 3. LLM Evaluation

Implemented `main.py` to evaluate the golden question set using the Llama 3.2 model through the local Ollama API.

For every question, the program:

1. Reads the question from the JSON file.
2. Sends the question to the Llama 3.2 model.
3. Receives the generated response.
4. Compares the response against the expected keywords.
5. Calculates keyword coverage.
6. Assigns a PASS or REVIEW status.

### 4. Keyword Scoring

Keyword coverage is calculated using:

```text
Score = (Matched Keywords / Total Keywords) × 100
```

Evaluation criteria:

- **PASS:** Score greater than or equal to 60%.
- **REVIEW:** Score below 60%.

The program also records matched and missing keywords for each question.

### 5. Baseline Results

The evaluation results are saved in `baseline_results.csv`.

The CSV contains:

- Question ID
- Question
- Expected answer
- LLM-generated answer
- Matched keywords
- Missing keywords
- Score
- Status
- Source
- Model name
- Release version

The program also displays a summary containing successful evaluations, PASS count, REVIEW count, errors, average keyword coverage, and evaluation date.
