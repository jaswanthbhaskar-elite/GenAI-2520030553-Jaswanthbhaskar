# Week 7 – Next-Token Probability Inspection

## Objective

Inspect logits and Top-K candidate tokens from a small open-source language model using Hugging Face Transformers.

## Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- DistilGPT-2

## Implementation

The practical uses the pretrained DistilGPT-2 model to inspect how a language model predicts its next token.

The program:

1. Loads the pretrained tokenizer and model.
2. Tokenizes the input prompt.
3. Displays input token IDs and tokens.
4. Extracts the next-token logits.
5. Applies Softmax to convert logits into probabilities.
6. Identifies and displays the Top-10 next-token candidates.
7. Displays the most probable next token.

## Input Prompt

```text
Artificial intelligence is
```

## Experimental Results

The model generated the following Top-10 candidates:

| 4 | one | 3.68% |
| 5 | an | 3.52% |
| 6 | now | 1.62% |
| 7 | becoming | 1.58% |
| 8 | also | 1.47% |
| 9 | just | 1.13% |
| 10 | still | 1.12% |

The most probable next token was `a`.

## Key Concepts

- **Logits:** Raw prediction scores generated by the model.
- **Softmax:** Converts logits into probability values.
- **Top-K:** Selects the K most probable next-token candidates.
- **Next-token prediction:** Predicts the next token based on the preceding context.
