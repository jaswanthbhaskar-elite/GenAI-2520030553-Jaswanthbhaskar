# Week 1 – Generative AI Practical

## Overview

This folder contains the implementation for Week 1 of the Generative AI practical laboratory.

The practical introduces the initial concepts and Python implementation used throughout the subsequent GenAI experiments.

## Project Structure

```text
week1/
├── .gitignore
├── main.py
└── requirements.txt
```

## Technologies Used

- Python
- Visual Studio Code

## Prerequisites

- Python 3.x
- pip (Python package manager)

## Setup and Execution

### 1. Navigate to the Week 1 folder

```bash
cd week1
```

### 2. Create a virtual environment

```bash
py -m venv .venv
```

### 3. Activate the virtual environment

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. Run the program

```bash
python main.py
```

## Files Description

| File | Description |
|---|---|
